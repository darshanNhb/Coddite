# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Coddite, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please email: **security@example.test** (replace with your actual security contact)

### What to include

- A description of the vulnerability
- Steps to reproduce
- The potential impact
- Any suggested fixes

### Response timeline

- **Acknowledgement:** within 48 hours
- **Initial assessment:** within 5 business days
- **Fix and disclosure:** coordinated with the reporter
